Neste arquivo estarei citando 3 boas práticas ao utilizar o Git e o GitHub:

1 - Usar branchs coerentes com os códigos que estiver subindo
exemplo: não utlizar uma branch criada para corrigir bugs para subir um código responsável por criar uma nova função no programa em desenvolvimento.

2 - Fazer observações objetivas e de fácil entendimento nos seus commits para que os demais integrantes da sua equipe entendam perfeitamente o que foi adicionado ou alterado no código que você estiver subindo.

3 - Evitar incluir arquivos sensíveis nos repositórios, como credenciais e dados pessoais não sejam incluídos nos repositórios.
